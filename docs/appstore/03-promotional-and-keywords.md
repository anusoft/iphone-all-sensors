# 03 · Subtitle, Promotional Text, Keywords, What's New

Version-attached fields. The subtitle and keywords are indexed by App Store search. Promo text and What's New can be edited without resubmitting for review.

## Subtitle (30 char limit)

Pick **one** — or use the first as default.

| Subtitle (≤30) | Char count | Angle |
|--|--|--|
| `Live data from 21 sensors`         | 26 | Functional, neutral. **Recommended.** |
| `Every sensor your iPhone has`      | 28 | Conversational, broad audience. |
| `21 sensors. One clean dashboard.`  | 32 ❌ over budget |
| `See what your phone really knows`  | 32 ❌ over budget |
| `Sensor explorer + data logger`     | 29 | Highlights the logger feature. |
| `Visualise every iPhone sensor`     | 29 | Highlights the Show-Off feature. |

## Promotional Text (170 char limit)

Edits without re-review — use it for current updates, sales, or to push the new feature.

```
74 full-screen sensor visualisations in Show-Off Mode. Live IMU, GPS, barometer, magnetometer. CSV/JSON export. HealthKit-aware. No analytics. Everything stays on device.
```

(170 chars — right at the limit.)

## Keywords (100 char limit, comma-separated, no spaces after commas)

Apple already indexes the app name and category — don't repeat them. Aim for searchable, related terms a real user would type.

```
sensor,accelerometer,gyroscope,gps,compass,altimeter,barometer,magnetometer,pedometer,imu,logger,csv
```

(100 chars — at the limit. Includes the most-searched sensor names.)

### Alternates if you want to swap focus

| Use case               | Keyword string (≤100) |
|------------------------|------------------------|
| Developer-leaning      | `sensor,imu,coremotion,corelocation,healthkit,logger,csv,debugging,tools,gps,compass,barometer` |
| Maker / hobbyist       | `sensor,gps,compass,level,altimeter,tilt,gyro,magnet,pedometer,steps,weather,torch` |
| Educational            | `sensor,physics,gps,compass,altitude,pressure,acceleration,gravity,steps,demo,classroom,stem` |

Don't keyword-stuff competitors' names or unrelated trending terms (e.g., "AI", "ChatGPT") — Apple rejects for keyword spam.

## What's New (4 000 char limit)

For v1.0, this is your launch announcement.

```
First public release.

• 21 device sensors with per-sensor detail screens
• Show-Off Mode — 74 full-bleed visualisations across all sensors. Tap the gradient banner on any sensor to enter; horizontal swipe switches sensor, vertical swipe cycles variant.
• Logger — multi-sensor recording with per-sensor sample rate; export to CSV or JSON
• HealthKit integration (read-only)
• Siri Shortcuts: "Get Sensor Reading", "Start/Stop Sensor Recording", "Export Sensor Data"
• Built for iPhone and iPad; supports portrait and landscape

If you find a sensor reading that looks wrong, please tell us — we want this to be the most honest sensor explorer on the App Store.
```
