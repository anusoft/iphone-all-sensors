Top-level metadata that doesn't change between versions. Set once when you create the App Store Connect record.

## Identity

| Field                         | Value                                            | Notes                                                       |
|-------------------------------|--------------------------------------------------|-------------------------------------------------------------|
| **App Name** (30 char)         | `All Sensors`                                    | Already wired as `INFOPLIST_KEY_CFBundleDisplayName`. 11 chars. |

| **Apple ID** (auto-assigned)   | _generated by App Store Connect on creation_      |                                                             |

## Categorisation

Apple gives 2 category slots. For a sensor visualisation tool that is half utility, half developer reference:

| Slot                  | Choice         | Why                                                              |
|-----------------------|----------------|------------------------------------------------------------------|
| **Primary Category**  | `Utilities`    | The functional fit — exposes device system data.                  |
| **Secondary Category**| `Developer Tools` | Signals the audience: makers, devs, hardware enthusiasts.       |

Alternative pairs if `Developer Tools` isn't accepted: `Utilities` + `Education`, or `Utilities` + `Reference`.

## Info.plist usage strings (already set — for reference)

These are already in `INFOPLIST_KEY_*` in the Xcode build settings. Reviewers WILL test that the prompts appear when permissions are requested, and that the strings explain *why*.

| Key                                            | Current string                                                                              |
|------------------------------------------------|---------------------------------------------------------------------------------------------|
| `NSLocationWhenInUseUsageDescription`          | We use your location to display GPS coordinates, altitude, speed, and compass heading.     |
| `NSLocationAlwaysAndWhenInUseUsageDescription` | This app uses your location to display GPS coordinates and compass heading.                |
| `NSMotionUsageDescription`                     | We use motion sensors to display accelerometer, gyroscope, pedometer, and activity data.   |
| `NSCameraUsageDescription`                     | We use the camera to show camera capabilities and control the torch/flashlight.            |
| `NSMicrophoneUsageDescription`                 | We use the microphone to show audio input device information.                              |
| `NSBluetoothAlwaysUsageDescription`            | We use Bluetooth to scan for nearby devices and display Bluetooth status.                  |
| `NSBluetoothPeripheralUsageDescription`        | This app uses Bluetooth to discover and display nearby devices.                            |
| `NSLocalNetworkUsageDescription`               | This app uses the local network to display network connectivity information.               |
| `NSHealthShareUsageDescription`                | We read health data such as steps, heart rate, and activity to display in the Health tab.  |
| `NSHealthUpdateUsageDescription`               | We can write workout and activity data to HealthKit.                                       |
| `NSFaceIDUsageDescription`                     | This app uses Face ID for biometric authentication testing.                                |

If you change any of these in Xcode, update them here.
