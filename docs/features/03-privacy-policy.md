# Feature 03: Create Privacy Policy

## Checklist

- [ ] Write privacy policy markdown document
- [ ] Host privacy policy (GitHub Pages or website)
- [ ] Add privacy policy link in SettingsSheet
- [ ] Add privacy policy URL to App Store Connect (when ready)
- [ ] Ensure policy covers all data collected by sensors
- [ ] State that sensor data does not leave device (if true)

## Details

**File:** `docs/privacy-policy.md`

**Required Sections:**
1. **Introduction** — What the app does
2. **Data We Collect** — List all sensor data types
3. **How We Use Data** — Display only, no server transmission
4. **Data Storage** — Local only, no cloud storage
5. **Third-Party Sharing** — None
6. **Your Rights** — GDPR/CCPA compliance notes
7. **Contact** — Support email

**In-App Integration:**
Add "Privacy Policy" button in SettingsSheet that opens Safari link.

## App Store Guideline
Section 5.1.1(i) — All apps must include a privacy policy link in App Store Connect AND within the app.
