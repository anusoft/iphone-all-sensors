# All Sensors - โปรแกรมดูเซ็นเซอร์ iPhone

แอป iOS ที่ครอบคลุมสำหรับแสดงข้อมูลแบบเรียลไทม์จาก **เซ็นเซอร์ iPhone ทั้งหมด** พร้อม UI ที่สวยงาม

สร้างด้วย **SwiftUI** และขับเคลื่อนโดย **Xiaomi MiMo 2.5 Pro** AI ผู้ช่วย

## คุณสมบัติ

### เซ็นเซอร์ที่รองรับ

| หมวดหมู่ | เซ็นเซอร์ |
|----------|-----------|
| **การเคลื่อนไหวและกิจกรรม** | เครื่องวัดความเร่ง, ไจโรสโคป, แมกนิโตมิเตอร์, การเคลื่อนไหวของอุปกรณ์, เครื่องนับก้าว, เครื่องวัดความสูง, การจดจำกิจกรรม |
| **ตำแหน่งและการนำทาง** | GPS (พิกัด, ความสูง, ความเร็ว), เข็มทิศ (ทิศเหนือจริง/แม่เหล็ก) |
| **สิ่งแวดล้อม** | บารอมิเตอร์ (kPa, hPa, inHg, mbar), เซ็นเซอร์วัดระยะ, ความสว่างหน้าจอ |
| **ระบบ** | แบตเตอรี่, โปรเซสเซอร์, หน่วยความจำ, พื้นที่จัดเก็บ, สถานะความร้อน |
| **การเชื่อมต่อ** | บลูทูธ (สแกน, อุปกรณ์), เครือข่าย (Wi-Fi/เซลลูลาร์) |
| **กล้องและเสียง** | ข้อมูลกล้อง, การควบคุมไฟฉาย |

### คุณสมบัติ UI

- **ข้อมูลแบบเรียลไทม์** อัปเดตสดเมื่อเคลื่อนย้ายอุปกรณ์
- **การแสดงผลที่สวยงาม**: เกจวงกลม, การวางแนวโทรศัพท์ 3D, หน้าปัดเข็มทิศ
- **ขั้นตอนการอนุญาต**: UI แนะนำอธิบายว่าทำไมแต่ละเซ็นเซอร์ต้องการการเข้าถึง
- **ค้นหา**: ค้นหาเซ็นเซอร์ใดก็ได้อย่างรวดเร็ว
- **หลายภาษา**: English, ไทย (ไทย), 中文 (จีน)
- **โหมดมืด**
- **บันทึกการวินิจฉัย** สำหรับดีบัก

## ข้อกำหนด

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+
- iPhone จริง (เซ็นเซอร์ส่วนใหญ่ต้องใช้ฮาร์ดแวร์จริง)

## การติดตั้ง

1. โคลน repository:
```bash
git clone https://github.com/anusoft/iphone-all-sensors.git
cd iphone-all-sensors/iPhoneSensors
```

2. เปิดใน Xcode:
```bash
open iPhoneSensors.xcodeproj
```

3. เลือก iPhone ของคุณเป็นอุปกรณ์เป้าหมาย

4. เซ็นชื่อแอปด้วย Apple ID ของคุณ:
   - คลิกโปรเจกต์ใน navigator
   - เลือก target "iPhoneSensors"
   - ใต้ "Signing & Capabilities" เลือก Team ของคุณ

5. สร้างและเรียกใช้ (`Cmd+R`)

6. บน iPhone ของคุณ ไปที่ **Settings → General → VPN & Device Management** และเชื่อถือโปรไฟล์นักพัฒนาของคุณ

## โครงสร้างโปรเจกต์

```
iPhoneSensors/
├── App/                    # จุดเริ่มต้นแอป
├── Views/
│   ├── Dashboard/          # แดชบอร์ดเซ็นเซอร์หลัก
│   ├── Sensors/            # มุมมองรายละเอียดเซ็นเซอร์
│   └── Components/         # ส่วนประกอบ UI ที่ใช้ซ้ำได้
├── Services/               # ตัวจัดการเซ็นเซอร์
├── Models/                 # โมเดลข้อมูล
└── Resources/              # การกำหนดค่าแอป
```

## สถาปัตยกรรม

- **SwiftUI** สำหรับ UI แบบประกาศ
- **ObservableObject** พร้อม `@EnvironmentObject` สำหรับการผูกข้อมูลปฏิกิริยา
- **CoreMotion** สำหรับเซ็นเซอร์การเคลื่อนไหว
- **CoreLocation** สำหรับ GPS และเข็มทิศ
- **CoreBluetooth** สำหรับการสแกน BLE
- **AVFoundation** สำหรับกล้อง/เสียง
