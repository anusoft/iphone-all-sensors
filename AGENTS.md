# Repository Instructions

## Apple Developer Configuration

- App name: All Sensors
- App bundle identifier: `com.1moby.allsensors`
- App ID prefix / Team ID: `D62Y8JVXB9`
- HealthKit must be enabled for this bundle identifier in Apple Developer Certificates, Identifiers & Profiles.
- The app target must keep the `com.apple.developer.healthkit` entitlement enabled.
- Do not enable Clinical Health Records unless the app is changed to read clinical records.
