# All Sensors - عارض مستشعرات الآيفون

تطبيق iOS شامل يعرض بيانات في الوقت الفعلي من **جميع مستشعرات الآيفون المتاحة** مع واجهات مستخدم جميلة.

مبني بـ **SwiftUI** ومدعوم بمساعد الذكاء الاصطناعي **Xiaomi MiMo 2.5 Pro**.

## المميزات

### المستشعرات المدعومة

| الفئة | المستشعرات |
|-------|-----------|
| **الحركة والنشاط** | مقياس التسارع, الجايروسكوب, مقياس المغناطيسية, حركة الجهاز, عد الخطوات, مقياس الارتفاع, التعرف على النشاط |
| **الموقع والملاحة** | GPS (الإحداثيات, الارتفاع, السرعة), البوصلة (الشمال الحقيقي/المغناطيسي) |
| **البيئة** | مقياس الضغط (kPa, hPa, inHg, mbar), مستشعر القرب, سطوع الشاشة |
| **النظام** | البطارية, المعالج, الذاكرة, التخزين, الحالة الحرارية |
| **الاتصال** | Bluetooth (المسح, الأجهزة), الشبكة (Wi-Fi/الخلوي) |
| **الكاميرا والصوت** | معلومات الكاميرا, التحكم في المصباح |

### مميزات الواجهة

- **بيانات في الوقت الفعلي** - تحديث مباشر عند تحريك الجهاز
- **تصورات جميلة**: مقاييس دائرية, اتجاه الهاتف ثلاثي الأبعاد, قرص البوصلة
- **تسلسل الأذونات**: واجهة إرشادية تشرح لماذا يحتاج كل مستشعر للوصول
- **البحث**: اعثر على أي مستشعر بسرعة
- **متعدد اللغات**: English, ไทย, 中文
- **الوضع الداكن**
- **سجلات التشخيص** للتصحيح

## المتطلبات

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+
- آيفون حقيقي (معظم المستشعرات تتطلب أجهزة حقيقية)

## التثبيت

1. استنساخ المستودع:
```bash
git clone https://github.com/anusoft/iphone-all-sensors.git
cd iphone-all-sensors/iPhoneSensors
```

2. فتح في Xcode:
```bash
open iPhoneSensors.xcodeproj
```

3. تحديد الآيفون كجهاز مستهدف

4. توقيع التطبيق بحساب Apple ID الخاص بك

5. البناء والتشغيل (`Cmd+R`)

6. على الآيفون, اذهب إلى **الإعدادات → عام → VPN وإدارة الأجهزة** وثق بملف المطور الخاص بك

## الهندسة المعمارية

- **SwiftUI** لواجهة المستخدم التصريحية
- نمط **ObservableObject** مع `@EnvironmentObject` لربط البيانات التفاعلي
- **CoreMotion** لمستشعرات الحركة
- **CoreLocation** للـ GPS والبوصلة
- **CoreBluetooth** لمسح BLE
- **AVFoundation** للكاميرا/الصوت
